# همیار کاروفناوری

نسخه پایلوت موبایلی، آفلاین و قابل نصب سامانه ثبت فرایند، ارزشیابی مبتنی بر روبریک و هم‌افزایی معلمان کاروفناوری.

## نشانی نصب

پس از فعال‌شدن GitHub Pages:

`https://amirkhaledyan.github.io/hamyar-karofanavari1/`

## نکته مهم

اطلاعات پایلوت در همان گوشی و در IndexedDB مرورگر ذخیره می‌شود. پیش از پاک‌کردن داده‌های Chrome، حذف برنامه یا تعویض گوشی، از داخل سامانه فایل پشتیبان تهیه کنید.
